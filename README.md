# geosite-blocked

Список популярных зарубежных доменов, независимо от того, заблокированы они в РФ или нет. Представляет собой аналог geolocation-!cn для России и предназначен для безопасной и эффективной маршрутизации на основе FakeIP.

**Обновление каждый понедельник.**

### Источники данных

- https://community.antifilter.download

- https://iplist.opencck.org (все категории)

- https://github.com/1andrevich/Re-filter-lists (community.lst и domains_all.lst **с фильтрацией**.)

* **Логика фильтрации:**
  * **Фильтрация по TLD:** Исключаются национальные доменные зоны (ccTLD), закрепленные за другими странами, **кроме зоны RU** (`.ru`, `.su`, `.рф` и т.д.), брендовые/корпоративные TLD (`.google`, `.apple` и т.д.).
  * **Проверка через DNS & GeoIP (`GeoLite2-Country.mmdb`):**
    * **Исключаем:** 
      * Домены, резолв которых явно вернул код страны, отличный от `RU`.
      * Нерезолвящиеся записи (ошибки DNS, `NXDOMAIN`, таймауты или отсутствие `A`-записей).
    * **Оставляем:** Случаи, когда GeoIP не смог определить код страны после успешного резолва.

* **Источники Tranco Top 30k и Geolocation JSON:**
  * [Tranco List](https://tranco-list.eu/) (топ-30 тыс. доменов через PyPI-пакет `tranco`)
  * [KaringX Ruleset](https://github.com/KaringX/karing-ruleset) (`geolocation-!cn.json` — списки `domain` и `domain_suffix`)

* **Общая логика фильтрации:**
  * **Проверка корректности:** Исключаются записи без точек (не являющиеся валидными доменными именами или суффиксами).
  * **Фильтрация по TLD:** Исключаются доменные зоны РФ (`.ru`, `.su`, `.рф` и др.), брендовые/корпоративные TLD (`.google`, `.apple` и т.д.), а также все остальные ccTLD.
  * **Фильтрация по ключевым словам:** Исключаются российские сервисы и ключевые слова (*yandex*, *vkontakte*, *sber*, *ozon*, *avito* и др.).
  * **Проверка через DNS & GeoIP (`GeoLite2-Country.mmdb`):**
    * **Исключаем:** 
      * Домены, резолв которых явно вернул код страны `RU`.
      * Нерезолвящиеся записи (ошибки DNS, `NXDOMAIN`, таймауты или отсутствие `A`-записей).
    * **Оставляем:** Случаи, когда GeoIP не смог определить код страны после успешного резолва.

- Файл с доменами в `data/community.lst` (можно предложить свои, включены национальные доменные зоны (ccTLD кроме RU),  которые были исключены в фильтрациях предыдущих списков.)

Для формирования итогового списка правил (`geosite-blocked`) так же используются проверенные категориальные наборы правил в формате JSON из репозиториев [DustinWin](https://github.com/DustinWin/ruleset_geodata) и [KaringX](https://github.com/KaringX/karing-ruleset). Из них автоматически извлекаются поля `domain` и `domain_suffix`, полный список доступен в папке `daata`.

### Результаты сборки и формат выгрузки

Процесс сборки итоговых наборов правил выстроен следующим образом:

1. **Сбор и объединение списков:**
   * Скачиваются свежие текстовые списки (списки Antifilter, Re-filter, OpenCCK), а также берутся ранее обработанные файлы `.lst` из директории `data/`.
   * Из всех строк удаляются комментарии, пробелы, префиксы `www.` и замыкающие точки. Домены приводятся к нижнему регистру.

2. **Оптимизация и дедупликация поддоменов (Subdomain Collapsing):**
   * Все уникальные валидные домены сортируются по длине (от коротких к длинным).
   * Если домен является поддоменом уже обработанного родительского домена (например, `sub.example.com` при наличии `example.com`), он отбрасывается. Это сводит итоговый список к минимально необходимому набору корневых родительских доменов для записи в `domain_suffix`.

3. **Генерация итоговых файлов:**
   * **`geosite-blocked.json`** — итоговый JSON-файл в формате Rule-Set (версия 3), где все оптимизированные домены записаны в массив `domain_suffix`.
   * **`geosite-blocked.srs`** — бинарный файл правили правил (Rule Set) для клиентских приложений (sing-box, karing и др.), скомпилированный утилитой `sing-box rule-set compile` из исходного JSON.

4. **Публикация и доставка:**
   * Сгенерированные файлы (`.json` и `.srs`) автоматически сохраняются в репозитории и создается новый **GitHub Release** с указанием количества доменов.
   * Для моментального обновления бинарного файла у пользователей сбрасывается кэш сети CDN через `jsDelivr Purge API`.
